Sky Pixel Atlas v2.5 — Modern Search-Bar Atlas

What changed
- Atlas launcher moved into the existing Sky Pixel search bar.
- New animated Aurora orb icon with “AI Atlas” label.
- Modern near-black chat panel.
- Blue-glowing message composer.
- New prompt cards shown when opening an empty/new chat.
- Existing voice mode, weather, places, nearby, teleport, map controls, history, and all manual UI controls remain intact.

Install
Replace the files in your map folder with the files in this package. Preserve the tools folder.
No Cloudflare Worker redeploy is needed because this is a frontend-only design update.
After replacing files, hard refresh with Ctrl+F5.
