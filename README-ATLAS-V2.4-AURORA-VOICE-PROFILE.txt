Sky Pixel Atlas v2.4 — Aurora Voice Profile

Adds:
- Aurora female voice profile as the default
- Automatic preference for Microsoft Aria Natural, Jenny, Samantha, Karen, Zira, Ava, and other female English voices
- Atlas male and System Default alternatives
- Saved voice-profile selection
- Calm Aurora pacing and slightly warmer pitch
- Existing Aurora Orb listening, thinking, and speaking states remain intact

Install:
Replace index.html, sky-pixel-ai-ui.js, sky-pixel-ai.css, and sky-pixel-ai-voice.js from this package.
No Cloudflare Worker redeploy is required for this voice-only update.
Hard refresh with Ctrl+F5.
